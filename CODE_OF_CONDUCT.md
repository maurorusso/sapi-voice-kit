# Código de conducta

## Alcance

`sapi-voice-kit` es un proyecto de un solo mantenedor. No se aceptan contribuciones de código externas (ver [CONTRIBUTING.md](CONTRIBUTING.md)) — este código de conducta rige los espacios donde sí hay interacción con otras personas: Issues, Discussions, y cualquier comentario o reporte.

## Qué se espera

- Tratar a los demás con respeto, incluso al reportar un bug o discrepar de una respuesta del mantenedor.
- Mantener los reportes enfocados en el proyecto: pasos para reproducir, comportamiento esperado vs. real, contexto técnico relevante.
- No usar Issues o Discussions para spam, promoción no relacionada, o ataques personales.

## Qué no se tolera

- Lenguaje abusivo, discriminatorio, o acoso de cualquier tipo hacia el mantenedor u otras personas que participen en Issues/Discussions.
- Publicar información privada de terceros sin su consentimiento.

## Aplicación

Este es un proyecto personal, no un equipo con proceso formal de moderación. El mantenedor puede cerrar, ocultar, o bloquear la participación en Issues/Discussions que no respeten lo anterior, a su criterio.

## Reportar un problema de conducta

Escribí por correo a la dirección de contacto listada en el perfil de GitHub del mantenedor ([@maurorusso](https://github.com/maurorusso)), o usá [GitHub Security Advisories](https://github.com/maurorusso/sapi-voice-kit/security/advisories/new) si el problema involucra también un riesgo de seguridad.
